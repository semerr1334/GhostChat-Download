📲 Как перекинуть файл с айфона на компьютер
  1. Жми СКАЧАТЬ → Safari спросит «Загрузить?» → жми Загрузить.
  2. Файл лежит в приложении Файлы → папка Загрузки.
  3. Перекинуть на ПК — любой способ:
    • Telegram: отправь файл себе в «Избранное» → открой Telegram на компе (ГОТОВО!);
    • iCloud Drive: «Поделиться» → Сохранить в Файлы → iCloud Drive → на компе icloud.com;
    • Гугл Диск — загрузи, на компе disk.google.com;
    • Кабелем: подключи к ПК, «Доверять этому компьютеру» → Фото/Файлы через проводник.
  4. На ПК: запусти EXE двойным кликом. Если SmartScreen напишет «неизвестный издатель» — жми Подробнее → Выполнить в любом случае (наш файл, вирусов нет, проверено побайтово ✔).
➕ Сделай иконку на экране «Домой»
  1. Ты уже на этой странице в Safari.
  2. Жми Поделиться (квадрат со стрелкой вверх).
  3. Листай вниз → «На экран "Домой"» → Добавить.
  4. Теперь Ghost Launcher — как приложение: тап и сразу список версий 👻
