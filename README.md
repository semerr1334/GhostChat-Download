# GhostChat 👻💬

**Свой мессенджер — регистрация по нику, без номера телефона!**

## 📥 Скачать APK (Android)
👉 **[GhostChat-v0.2.apk](../../releases/latest)** — скачивание без логина, жми и ставь.

## ✨ Что умеет (v0.2)
- 🔑 Регистрация по **никнейму** — никаких номеров и СМС
- 💬 Личные чаты 1-на-1, сообщения доходят мгновенно
- 🔍 **Поиск людей по нику** (кнопка 🔍)
- 🌐 Веб-клиент — прямо из браузера
- 📜 История чатов на сервере, офлайн-доставка

## 🌐 Веб-версия
Адрес пишется здесь в релизах (демо-сервер живёт на временном хостинге, скоро переезд на постоянный).
