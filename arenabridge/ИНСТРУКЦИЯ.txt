ЧТО ЭТО ДАСТ:
  • OmniRoute — локальный шлюз: все модели Arena (и ещё 350+
    провайдеров) через одну точку http://localhost:20128
  • Claude Code — агент, который НЕ БОЛТАЕТ, А ДЕЛАЕТ:
    создаёт файлы, запускает команды, пишет код по твоим приказам.

НУЖНО ОДИН РАЗ ПО КНОПКАМ:
------------------------------------------------------------
ШАГ 0. В браузере зайди на https://lmarena.ai и ВОЙДИ в аккаунт
       (через Google). Без входа кука не появится.
       ⚠️ Потом НЕ нажимай «выйти» в браузере — иначе кука умрёт.

ШАГ 1. Запусти  1-install-omniroute.bat
       Он сам скачает установщик (500 МБ) и запустит его.
       Ставь как обычную программу (Next → Install).
       Запусти OmniRoute — откроется её окно (Dashboard).
       Держи её открытой (можно свернуть — она живёт возле часов).

ШАГ 2. Запусти  2-find-cookie.bat
       Найдёт куку arena.ai и ПОЛОЖИТ В БУФЕР ОБМЕНА.
       В окне OmniRoute:
         → Providers (или Connections)
         → найди «LM Arena» (префикс lma)
         → Connect / Add → в поле Cookie вставь (Ctrl+V) → Save
         → нажми Test: ЗЕЛЁНЫЙ = победа 🎉
       Если куку не нашло: открой lmarena.ai в браузере (Opera/Chrome),
       обнови страницу, подожди 10 сек, запусти 2-find-cookie.bat снова.

ШАГ 3. Запусти  5-test.bat — проверка, что шлюз отвечает.
       Должно написать «ВСЁ ЖИВО! Моделей видно: NN».

ШАГ 4. Где брать API-ключ для клиентов:
       В OmniRoute Dashboard найди раздел API Keys (или Settings → API)
       — скопируй ключ вида sk-... Он понадобится на шаге 6.

ШАГ 5. Запусти  3-install-agent.bat
       Ставит Node.js (если нет — откроет страницу, качни LTS и повтори)
       и агента Claude Code.

ШАГ 6. Открой ПАПКУ СВОЕГО ПРОЕКТА (или просто рабочую папку),
       в ней запусти  4-run-agent.bat
       → вставь ключ из шага 4 (или просто Enter)
       → модель: Enter (= auto/coding, шлюз сам выберет лучшую рабочую)
       → открылся Клод. ПИШИ ПРИКАЗЫ:
         «создай файл привет.txt с текстом Сёма крут»
         «сделай папку test и положи туда два файла»
         «объясни этот код» / «напиши сайт-визитку»
       Он не болтает — он ДЕЛАЕТ. 🔥

ЕЖЕДНЕВНАЯ РАБОТА (после настройки):
  Включил комп → OmniRoute уже в трее → запустил 4-run-agent.bat → командуй.

------------------------------------------------------------
ЧАСТЫЕ ПОЛОМКИ И ДОКТОР:
------------------------------------------------------------
❌ В Test у провайдера красное / ошибка 401 / 500 (no body)
   = кука умерла (живут неделями, но не вечно).
   ЛЕЧЕНИЕ: зайди на lmarena.ai, НЕ выходя обнови страницу,
   запусти 2-find-cookie.bat снова, вставь новую куку в провайдера lma.

❌ Клод пишет «model not found»
   = имя модели кривое. Лечение: в 4-run-agent.bat на шаге 2
   жми просто Enter (auto/coding) или скопируй точный id модели
   со страницы Models в интерфейсе OmniRoute (вида lma/что-то).

❌ llmarena prosi captcha / cloudflare
   = арена придралась. Подожди 10–15 минут, обнови куку (шаг 2).

❌ OmniRoute не отвечает (5-test.bat ругается)
   = приложение закрыто. Запусти OmniRoute из Пуска.

------------------------------------------------------------
СЕКРЕТНО МЕЛКИМ ШРИФТОМ (читать обязательно!):
  • Кука arena-auth = ПОЛНЫЙ ДОСТУП к твоему аккаунту арены.
    Не шли её никому, даже «поддержке». Хранится только у тебя
    на ПК и в твоей локальной OmniRoute.
  • У Арены нет официального API — это «народный» мост. Если
    завтра Арена всё поменяет — мост сломается, я пришлю обнову.
  • Лимиты у арены есть не бесконечные. OmniRoute умеет
    сам переключаться на запасные модели (Combo / auto/coding) —
    если одна упрётся в лимит, подхватит другая.
  • Через http://localhost:20128/v1 + твой ключ можно
    подключить ЛЮБОГО клиента с поддержкой OpenAI API
    (чат-программы, расширения VS Code и т.д.).

Удачи, капитан. Команды принимает мост 🌉👻
